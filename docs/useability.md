Mengapa Harus Dilakukan : 

1. **Menemukan masalah dari sudut pandang pengguna, bukan pembuat**  
   Developer/siswa yang bikin website sudah terlalu familiar sama produknya sendiri, jadi sering nggak sadar ada bagian yang membingungkan buat orang lain. User asli (apalagi yang belum pernah lihat sebelumnya) akan langsung ketahuan di mana dia bingung, nyasar, atau nge-klik salah.  
2. **Meningkatkan kepuasan & kepercayaan pengguna**  
   Kalau UMKM/pemilik toko yang jadi klien pakai websitenya sendiri dan ternyata gampang, mereka jadi lebih percaya sama hasil kerja siswa dan lebih mungkin benar-benar memakainya untuk bisnis.  
3. **Memvalidasi apakah tujuan fungsional tercapai**  
   Website bisa saja "berfungsi" secara teknis (nggak error, kodenya jalan) tapi tetap gagal secara usability kalau user nggak bisa nemuin fitur pentingnya. Testing ini yang membedakan "bisa jalan" VS "benar-benar bisa dipakai."  
   

# **1\. Petunjuk Pengujian**

Usability testing ini dilakukan terhadap 5 responden. Berdasarkan penelitian Jakob Nielsen, pengujian dengan 5 pengguna sudah mampu menemukan sekitar 85% masalah usability pada suatu produk.

* Setiap responden diminta menyelesaikan seluruh task pada Tabel Daftar Task tanpa dipandu

* Penguji mencatat waktu penyelesaian, keberhasilan, jumlah error, dan catatan perilaku responden.

* Setelah seluruh task selesai, responden mengisi Kuesioner Kepuasan Pengguna.

* Hasil dari 5 responden direkap pada Tabel Rekapitulasi untuk ditarik kesimpulan.

# **5\. Kuesioner Kepuasan Pengguna**

Isi dengan skala 1–5 untuk setiap pernyataan (1 \= Sangat Tidak Setuju, 2 \= Tidak Setuju, 3 \= Cukup, 4 \= Setuju, 5 \= Sangat Setuju). Semua pernyataan bersifat positif, jadi skor tinggi \= penilaian baik.

| No | Pernyataan | R1 | R2 | R3 | R4 | R5 |
| ----- | ----- | ----- | ----- | ----- | ----- | ----- |
| 1 | Website ini mudah digunakan |  |  |  |  |  |
| 2 | Tampilan / desain website ini menarik |  |  |  |  |  |
| 3 | Menu dan navigasi website ini jelas dan tidak membingungkan |  |  |  |  |  |
| 4 | Saya bisa menemukan informasi yang dicari dengan cepat |  |  |  |  |  |
| 5 | Fitur-fitur pada website ini berfungsi dengan baik |  |  |  |  |  |
| 6 | Ukuran teks dan gambar pada website ini nyaman dilihat |  |  |  |  |  |
| 7 | Saya merasa percaya diri saat menggunakan website ini tanpa bantuan orang lain |  |  |  |  |  |
| 8 | Secara keseluruhan, saya puas dengan website ini |  |  |  |  |  |
| **Total Skor (jumlah semua nilai)** |  |  |  |  |  |  |
| **Rata-rata (Total ÷ 8\)** |  |  |  |  |  |  |

**Cara Menghitung (lebih sederhana, tanpa rumus kebalikan):**

* Jumlahkan nilai 8 pernyataan untuk tiap responden → Total Skor (rentang 8–40)

* Total Skor dibagi 8 → hasilnya Rata-rata per responden (skala 1–5)

* Rata-rata dari kelima responden \= Skor Kepuasan Akhir website

**Kategori Skor Rata-rata (skala 1–5):**

| Rata-rata | Kategori |
| :---: | ----- |
| 4,20 – 5,00 | Sangat Puas |
| 3,40 – 4,19 | Puas |
| 2,60 – 3,39 | Cukup Puas |
| 1,80 – 2,59 | Kurang Puas |
| 1,00 – 1,79 | Tidak Puas |
